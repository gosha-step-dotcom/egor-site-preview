# Источники медиа для главной
- `astronaut.glb` — модель «Z2 Spacesuit», NASA 3D Resources (github.com/nasa/NASA-3D-Resources), public domain. Обработка: снято Draco-сжатие, текстуры 1024 px WebP, квантование вершин.
- `moon-albedo.jpg`, `moon-normal.jpg` — из «Moon - Southern Sea», NASA 3D Resources, public domain. Обработка: высокие частоты, бесшовность, карта нормалей из яркости.
- `moon-disc.jpg` — «Moon», `earth-disc.jpg` — «Earth (B)», `mars.jpg` — «Mars», `jupiter.jpg` — «Jupiter»; NASA 3D Resources, public domain. Обработка: диски вырезаны по контуру, уменьшены.
